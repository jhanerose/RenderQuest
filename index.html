Evaluation Log & Answer Key
13. In vs Uniform: An in variable receives unique, per-vertex data directly from the VBO. A uniform variable receives global data from the CPU that remains exactly the same for all vertices processed during that specific draw call.
14. Magnitude & Unit Vector: The formula is: |v| = √(vx² + vy² + vz²). To create a unit vector, divide the original vector by its magnitude.
15. Fragment Shader: Decides the final color of the pixel that the fragment covers, applying colors, lighting, and textures.
16. Shader Program: A compiled and linked group of shaders. Steps: glCreateShader, glShaderSource, glCompileShader, glCreateProgram, glAttachShader, glLinkProgram.
17. Depth Test: Decides whether a fragment should be drawn based on distance from the camera (Z-buffer).
18. Dot Product (Angle): v1 · v2 = |v1| × |v2| × cos(θ)
19. glBufferData: Uploads vertex data array from system RAM (CPU) into graphics memory (GPU).
20. Z-value of 0.0f: In a basic 2D drawing, depth is irrelevant. Because it faces the camera perfectly flat, z = 0.0.
